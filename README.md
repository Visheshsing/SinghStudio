# Singh Digital Photostudio & Photocopy

Website for Singh Digital Photostudio & Photocopy, a local photography, printing, framing, and photocopy studio serving Rudrapur, Deoria since 1993.

**Live website:** [singhstudio.netlify.app](https://singhstudio.netlify.app/)

## Features

- Responsive layout for desktop and mobile
- Dark, gold-accented studio design
- Interactive camera-inspired hero and service cards
- Draggable photo gallery with full-size lightbox viewing
- Studio information, services, contact links, and embedded map

## Built with

- HTML
- CSS
- Vanilla JavaScript
- Google Fonts and Font Awesome

This is a static website. It does not require a framework, package installation, or build step.

## Run locally

Open `index.html` in a browser, or start a local server from the project directory:

```powershell
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Deploy with Netlify

Connect the GitHub repository to Netlify and use these settings:

- **Build command:** leave blank
- **Publish directory:** `.`

Netlify serves `index.html` and the accompanying asset folders directly from the project root.
